# Danny900714 Tap

## How do I install these formulae?

`brew install danny900714/tap/<formula>`

Or `brew tap danny900714/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "danny900714/tap"
brew "<formula>"
```
